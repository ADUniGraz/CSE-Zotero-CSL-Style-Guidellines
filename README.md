# CSE Zotero citation style

Citation style for Contemporary Southeast Europe (CSE), following the CSE Instructions for Authors, Section 7 (hybrid Chicago author-date).

## Install
1. Download the file cse-chicago-author-date.csl (click it, then the download icon).
2. In Zotero: Edit > Settings > Cite > Styles > Add from file... and choose the file.
3. In Word: Zotero tab > Document Preferences > select "CSE - Contemporary Southeast Europe (Chicago author-date)".
